Helper Workflow

This is the broadest CLI model for the helper surface. It uses `arr()`, `collect()`, `str()`, `num()`, `flag()`, `datetime()`, `filesystem()`, `doc()`, HTTP helpers, and `Hash` without needing a web server.

Run It

composer install
php examples/helpers/workflow.php
