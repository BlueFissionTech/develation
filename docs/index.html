DevElation

Blue Fission's PHP foundation for primitive value objects, resources, behaviors, storage, services, connections, parsing, CLI, HTML, and lifecycle utilities.

Install From Packagist View Source Browse Examples Read The Wiki
composer require bluefission/develation

Foundation Surface

DevElation stays below the application layer so Opus, BlueCore, Reactor, Automata, Annex, JenSS, Materia, Kyber, and microservices can compose it cleanly.

Primitive Family

Val, Str, Arr, Num, Flag, Date, Func, Ref, Obj, and collections with fluent lifecycle behavior and static helper dispatch.

Resource Lifecycle

Ref wraps references, resources, stream handles, process pipes, ownership policy, cursor movement, truncation, and chunks.

Data And Services

Storage, queues, schema, graph, request/response, mapping, clients, connections, and system utilities with substitutable contracts.

Hosted Examples

Static GitHub Pages tutorials and Codespaces commands demonstrate CLI scripts, web examples, helper workflows, and HTTP packet construction.

Stable Release

  • PHP 8.2+ package baseline.
  • Green CI on PHP 8.2 and PHP 8.3.
